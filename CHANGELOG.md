# Changelog

## 0.1.0 - experimental release candidate

- Horizontal context wrapper for the raw ComfyUI H3 visual VAE: native-width, 128 px and 384 px comparisons.
- Original-canvas crop with explicit shape checks; caller-owned model loading, dtype, inference and memory management.
- Matched forest/temple measurements, weight/latent provenance and seam close-ups.
- Installation instructions, CPU output-buffer example and geometry/contract tests.
- Optional static viewer source. Camera sliders no longer change the selected scene.

No original-code license selected yet. The packaged callable has not been rerun against real H3 weights; the original harness produced the GPU evidence. Pole mappings and alternative periodic tile assembly remain experimental. No upscaling or seam-noise repair claim is included.
